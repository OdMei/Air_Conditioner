## 本次完成

- 修正 YOLOv2 候选限框循环的尾后访问。0、1、10、244、245 候选分别验证原地输出与独立输出，缓冲守卫保持完整。实际模型为单人体类别，清理了旧的双类别配置说明。
- 红外完整帧消费为一次性事件。POWER、MODE、ECO、SLEEP、SWING 不随轮询反复执行；温度加减支持约 200 ms 的按住连发。
- DHT11 字节超时独立报告错误，整帧失败不覆盖旧值；修正负温度小数符号。温度与湿度的有效性和新鲜度分别判断，湿度失效不会抹掉有效温度。
- 将 DHT11/AP3216C 采样移至传感器线程，输入线程保留触摸、实体按键、红外和控制更新。DHT 缺失采用最高 60 秒退避；AP 连续三次读取失败后，5 秒退避重新初始化。
- UART 使用 4096 字节固定队列，应用日志整行入队，低优先级线程发送；单次最多 64 字节，HAL 超时 10 ms。显示排队、丢弃与发送错误，并在日志记录完整显示周期和输入轮询间隔。
- NN/PP/ISP 等待改为有限等待。相机线程监督启动、显示停帧和输入/输出异常，停止发布并等待三个工作线程确认停止后，才反初始化相机、重置队列和重启。每次故障最多三次重试，持续正常五秒后重置重试预算。
- 若 NPU 尚未返回、两秒内不能确认所有工作线程停止，保留缓冲并显示明确错误，不强制复位或回收运行中的 NPU 内存。此类故障需要后续实板定位或 RESET。
- 帧编号和采集时间从相机缓冲传到后处理。人数新鲜度使用采集时间，旧帧不会因处理完成而重新变成新鲜数据；AI Hz 改为完成次数窗口计量。
- DEBUG 增加最多十个人体框与置信度，坐标按推理/显示两路实际裁剪关系转换。过期或无效结果隐藏旧框；原有 DIAG 开合、滑动冻结和透明背景保留。
- LCD 前景等待自身 VBlank 切换完成后才复用缓冲。按脏矩形复制/清理缓存，镜像基线也及时清理，保持交错局部更新正确；50 ms 等待超时保留待绘内容。
- PC 模拟器按固定虚拟采样/控制步长推进，渲染使用墙钟；1 倍/60 倍及 50、100、500 ms 调度抖动结果一致。删除旧控制入口，测试统一调用生产状态逻辑。

未接真实温湿度传感器时，实板显示缺失；不生成假环境数据。框、UART 和自动恢复的实板效果仍需要烧录后验收。本次没有加入 ADC 电位器、BH1750、EEPROM、网络或新模型。
