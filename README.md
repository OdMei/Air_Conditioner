# N647 视觉感知智能空调

本项目基于正点原子 STM32N647 开发板，面向智能空调控制和嵌入式视觉感知演示。系统使用摄像头和 NPU 识别人和人数，结合温湿度、光照、红外、触摸屏和用户按键，自动判断在场、无人和睡眠状态，并通过四路隔离继电器控制模拟负载。

当前版本用于低压安全演示，可连接 5V/12V 风机、低压灯泡或继电器线圈。N647 只输出低压控制信号，不直接连接 220V 市电。

## 项目功能

- 摄像头人体检测和人数统计
- 在场、无人待机、睡眠节能和手动控制
- 温度、湿度和光照采集
- 电容触摸 LCD 和 LVGL 交互界面
- 调试模式：显示摄像头画面、检测人数、环境数据、模式和四路继电器状态
- 用户模式：显示温湿度、运行模式、设定温度并支持触摸调节
- 以太网或无线终端语音控制
- 红外遥控和板载按键控制
- RS485 外接 Modbus 传感器、功率计或电表
- RS232 调试日志和维护配置
- 音频提示、故障报警和状态反馈
- 四路独立负载控制

## 四路输出

| 通道 | 名称 | 当前用途 |
|---|---|---|
| Relay 1 | `Relay_Compressor` | 压缩机模拟负载 |
| Relay 2 | `Relay_Fan` | 低压风机 |
| Relay 3 | `Relay_3` | 预留扩展通道 |
| Relay 4 | `Relay_Aux` | 通用备用负载 |

控制逻辑会保证风机和压缩机的启动、停止顺序，并预留压缩机最小开停机时间、无人待机、故障关闭和紧急停止策略。

## 用户界面

### 调试模式

调试模式用于开发和维护，显示摄像头实时画面、人体检测框、人数、AI 帧率、温湿度、光照、当前状态、设定温度、四路继电器、网络和传感器状态。

### 用户模式

用户模式隐藏底层诊断信息，提供当前温度、湿度、运行模式、设定温度、开关机、模式选择和触摸调温等功能。

LVGL 只负责显示和产生用户操作事件，所有继电器动作由统一的空调控制状态机执行。

## 开发基础

本项目以已验证的 `991_AI_People_Detection` 为视觉基础，后续集成：

- `27_Touch`：电容触摸驱动参考
- `61_NetXDuo_TCP_Client`：以太网通信参考
- `30_DHT11`：温湿度采集
- `24_AP3216C`：光照采集
- 红外、RS232、RS485、音频和用户按键接口

YOLO11n 作为后续模型迁移目标。模型替换只调整 AI 模型适配和后处理，不改变界面、通信和继电器控制接口。

## 运行前提

首次运行需要按照 [烧录说明](docs/烧录说明.md) 将 FSBL、应用程序和 NPU 模型数据烧录到外部 Flash。`991_AI_People_Detection` 不依赖 SD 卡运行，但必须烧录 `network-data.hex` 才能完成推理。

接入实际 220V 风机或压缩机时，必须使用合格的交流接触器、保险、漏保、热保护和硬件急停，并由具备资质的人员完成电气施工。普通继电器模块和开发板不能直接切换市电负载。
