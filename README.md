# N647 视觉感知智能空调

本项目基于正点原子 STM32N647 开发板，面向智能空调控制和嵌入式视觉感知演示。系统使用摄像头和 NPU 识别人和人数，结合温湿度、光照、红外、触摸屏和用户按键，自动判断在场、无人和睡眠状态，并计算制冷、风机、摆风和灯光四路控制请求。当前尚未接入外部负载。

当前版本通过 LCD 和诊断日志展示软件控制请求，尚未配置物理负载 GPIO。外接负载、驱动电路及输出映射属于后续接入范围。

[克隆、构建与配套烧录文件说明](docs/git-quickstart.md) · [当前已验收的并排温湿度小卡界面](docs/ui-bento-compact-20261014.md)

## 项目功能

- 摄像头人体检测和人数统计
- 在场、无人待机、睡眠节能和手动控制
- 板载光照采集与外接 DHT11 温湿度采集接口；未接 DHT11 时显示温度不可用
- 电容触摸 LCD 与 LVGL 双模式界面
- 调试模式：显示摄像头画面、检测人数、环境数据、模式和四路软件请求
- 用户模式：显示温湿度、运行模式、设定温度并支持触摸调节
- 红外遥控和板载按键控制
- USART1 串口诊断日志
- AI／传感器有效性、过期识别及故障降级
- 温度迟滞、人工模式与统一的软件控制请求
- 中文卡片界面、PC 故障注入及仿真时间快进
- 与模型一致的摄像头检测视野、可调持续温湿度提醒
- 最近四条人员／环境事件、附近显示帧缩略图和手动拍照回看（RAM 记录）

工程已接入板载 AP3216C 光照传感器和正点原子小红外遥控器。光照低于 100 判定为暗，达到 200 判定为亮，中间区域保持上一次结果，避免状态抖动。有人且无光时进入自动睡眠，有人且有光时恢复在场状态；无人持续 10 分钟进入自动节能，持续 30 分钟自动关机。红外按键可以调节电源、温度、风速 1–5 档、强劲、左右/上下摆风、灯光、睡眠、节能和模式。

风速、摆风、灯光和节能状态目前已在状态机及 LCD 上生效，四路继电器的实际输出映射仍需根据外接低压演示负载单独接入。

## 四路软件控制请求

| 通道 | 名称 | 当前用途 |
|---|---|---|
| R1 / `0x01` | 制冷请求 | 温控与保护逻辑生成的制冷意图 |
| R2 / `0x02` | 风机请求 | 电源开启时的有效风档请求 |
| R3 / `0x04` | 摆风请求 | 左右或上下摆风启用 |
| R4 / `0x08` | 灯光请求 | 灯光标志启用 |

当前纯软件控制包含 ±1°C 温度迟滞、30 秒最小停机演示保护、温度失效取消制冷请求和关机清除全部请求。具体 GPIO 映射、负载驱动、风机延时关闭及真实设备保护参数需要在负载确定后实现。

## 用户界面

### 调试模式

视觉页面保留摄像头实时画面与人体框，顶部显示相机 FPS、AI 更新率和触摸状态；点击“诊断”展开可滚动的硬件信息，点击“返回主页”返回。

### 用户模式

当前源码为Bento鲜艳融合首页：增强静态蓝色波浪，亮绿温度与青色湿度改为一行两张148×70px小卡，数字放大到40px，单位20px；彩色区域比原大卡减少约65%。252px圆环与96px设定读数保留，支持64px加减和拖环调温。底部六项统一Noto16两行文字与28px图标，原数据、记录、提醒、视觉及诊断功能保留。并排小卡版已于2026-10-15烧录并完整回读校验，模型与FSBL保持一致；用户切回Flash启动后已确认本版新界面、调温、触摸和摄像头正常。

LVGL 显示快照并产生统一操作事件，控制请求由纯 C 逻辑计算。模式切换智能自动／手动制冷，睡眠和节能会改变执行目标及风档；手动模式不执行人员自动关机。按钮选中状态以控制快照为准。当前没有物理继电器执行器。

## 电脑预览界面

使用 VS Code 打开 [LVGL 预览工作区](simulator/lvgl-preview.code-workspace)，按 F5 选择“PC 界面预览”，或运行“预览：运行”任务，即可在独立的 Windows 窗口中查看并操作现有的 `800×480` 用户页和调试页。

电脑预览与开发板共用页面、按钮回调和空调逻辑。默认模拟环境为 27°C、湿度 55%、1 人、光照 250，逻辑电源关闭、目标温度 26°C；鼠标代替触摸，键盘可调整人员和环境数据。调试页显示 RGB565 测试背景，详细操作见 [预览说明](simulator/README.md)。

这些是模拟数据；预览不会连接开发板，也不显示其当前摄像头画面。`C/A/S` 切换模拟故障，`F` 切换 1×／60× 仿真时间，`R` 重置演示。

## 开发基础

本项目以已验证的 `991_AI_People_Detection` 为视觉基础，后续集成：

- `27_Touch`：电容触摸驱动参考
- `61_NetXDuo_TCP_Client`：以太网通信参考
- `30_DHT11`：温湿度采集
- `24_AP3216C`：光照采集
- 红外、RS232、RS485、音频和用户按键接口

YOLO11n 作为后续模型迁移目标。模型替换只调整 AI 模型适配和后处理，不改变界面、通信和继电器控制接口。

## 运行前提

首次运行需要按照 [烧录说明](docs/烧录说明.md) 将 FSBL、应用程序和 NPU 模型数据烧录到外部 Flash。`991_AI_People_Detection` 不依赖 SD 卡运行，但必须烧录 `network-data.hex` 才能完成推理。

接入实际 220V 风机或压缩机时，必须使用合格的交流接触器、保险、漏保、热保护和硬件急停，并由具备资质的人员完成电气施工。普通继电器模块和开发板不能直接切换市电负载。
